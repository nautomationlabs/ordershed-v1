Built so far

Foundation
  • React + TypeScript web app, code split by role
  • Typed API layer: runs on sandbox data; the real backend plugs in behind it
  • Design system: Archivo, Public Sans, IBM Plex Mono; flat, 1 px rules, 4 px radius
  • Desktop shell with 224 px sidebar and footer key bar; phone shell with four tabs
Shared components
  • Dense table: sort, filter, column chooser, saved layout, bulk select, export, keyboard
  • Status chip (word + colour), source tag on every number
  • "Proposed by AI" box with confidence and Approve / Edit
  • Document flow, DoA strip, commitment card, sealed-bid hash, command bar
Rules built into the code
  • Money is computed in code: normalised and landed cost, savings, 3-way match, DoA
  • A number cannot render without its source Computed
  • Nothing AI-drafted is sent without a person's tap
  • Buyer name hidden from suppliers until award; floor price private; tier never changes rank

Deployable on AWS (Mumbai)

Hosting

Private S3 bucket behind CloudFront with origin access control, strict security headers and SPA routing, as one CloudFormation template.

Pipeline

GitHub Actions typechecks, tests and builds every change, then deploys on merge using short-lived AWS credentials. No stored keys.

Container option

An nginx image for ECS Fargate, if we want the web app and API on the same platform.

What comes next
